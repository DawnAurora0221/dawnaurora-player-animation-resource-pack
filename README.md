## 📖 关于项目 / About The Project

**🌍 English:**
Welcome to **DawnAurora**! This is a fully open-source Minecraft Java Edition animation project. Developed entirely by a solo independent developer, all JSON models and animation codes are **100% hand-coded** (No AI generation, no stolen assets). 

We focus on a minimalist "Inheritance-based" code architecture. Our goal is to provide the smoothest and most natural animation experience with the absolute minimum file size, ensuring that even low-end devices (like Snapdragon 660) can run perfectly without any lag.

**🇨🇳 中文:**
欢迎来到 **DawnAurora**！这是一个完全开源的 Minecraft Java 版动作优化项目。本项目的所有 JSON 模型与动画代码均由独立开发者 **100% 纯手搓**（拒绝 AI 生成，拒绝盗用素材）。

我们致力于研究极简的“继承路线”代码架构。我们的目标是：用极小的文件体积，为玩家提供最流畅、最自然的动作体验。即使是低配手机（如骁龙 660）也能满帧流畅运行。

## ⚠️ 前置要求与兼容性 / Dependencies

在安装本资源包之前，请**务必**检查以下条件，否则动画不会生效！

*   ✅ **Game Version / 游戏版本**: **Minecraft 1.20.1** ONLY. (Fabric / Forge)
*   ✅ **Mandatory Mods / 强制前置**:
    *   **EMF (Entity Model Features)**
    *   **ETF (Entity Texture Features)**
*   ❌ **OptiFine / 高清修复**: **严格不兼容！** (Strictly NOT supported. Please remove OptiFine, or animations will break).

## 🛠️ 安装与配置教程 / Installation & Configuration

很多玩家反馈“装了没效果”或者“第一人称手抽搐”，请严格按照以下步骤操作：

1. 📥 下载对应版本的 `.zip` 资源包文件。
2. 📂 将 `.zip` 文件放入 `.minecraft/resourcepacks` 文件夹。
3. 🎮 启动游戏，进入 `选项 (Options)` -> `资源包 (Resource Packs)`，启用 DawnAurora。
4. ⚙️ **【极其重要的一步】第一人称防脱模设置**：
    *   在资源包界面，点击左侧的 **EMF 设置按钮（苦力怕图标）**。
    *   进入 `Models` -> `Player Settings`。
    *   找到并开启 **"Prevent first person hand animation"**（阻止第一人称手部动画）。
    *   *(这是保证你第一人称视角不穿模、不抖动的核心设置！)*
5. 🔄 建议按 `F3 + T` 重载资源包，或者完全重启游戏。

## 🐛 常见问题排查 / FAQ

**Q: 为什么我的动作依然是原版僵硬的？**
A: 请检查是否安装了 EMF 和 ETF 模组。如果是 Fabric 端，确保 Mods 文件夹里没有装 OptiFine。进入游戏按 F3+T 刷新。

**Q: 为什么袖子/皮肤外层还是脱模？**
A: 请回到上方的【安装与配置教程】第 4 步，务必在 EMF 设置中开启 `Prevent first person hand animation`。另外，请确保你没有安装其他的 3D 皮肤类模组（如 3D Skin Layers）与它产生冲突。

**Q: 可以在服务器里用吗？**
A: 完全可以！这是一个纯客户端资源包，只要你装了前置，进任何服务器都能看到自己的萌系动作。
